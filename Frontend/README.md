# Frontend — Sistem Review Kantin

Aplikasi frontend berbasis **React + TypeScript + Vite + Axios + React Router** untuk mengelola dan menampilkan data warung kantin serta autentikasi pengguna.

## Instalasi & Menjalankan

1. Install dependencies:
   ```bash
   npm install
   ```
2. Salin `.env.example` menjadi `.env` (jika belum ada):
   ```env
   VITE_API_BASE_URL=http://localhost:3000
   ```
3. Jalankan server pengembangan:
   ```bash
   npm run dev
   ```
4. Buka browser di `http://localhost:5173` (pastikan server backend Express sudah berjalan di `http://localhost:3000` dengan CORS diaktifkan).
